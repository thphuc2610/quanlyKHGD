# Prototype Streamlit

Thư mục này chứa bản prototype Python/Streamlit dùng để đối chiếu nhanh nghiệp vụ KLGD trước khi chuyển sang hệ thống chính thức Spring Boot + React.

## Nội dung

- `Web_final.py`: ứng dụng Streamlit prototype.
- `requirements.txt`: thư viện Python cho prototype.
- `input/`: file Excel mẫu đầu vào.
- `output/`: file Excel mẫu hoặc kết quả thử nghiệm.
- `.venv/`: môi trường Python cục bộ, không commit.

## Chạy prototype

```powershell
streamlit run Web_final.py
```
